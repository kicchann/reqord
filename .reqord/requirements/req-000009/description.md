# CLIメッセージ統一

## 概要

CLIの全出力メッセージ（エラー・情報・警告）を英語に統一する。
npm publishによるグローバル展開に向けて、言語の壁を取り除く。
また、共通のエラーハンドリング基盤による一貫したフォーマットを維持する。

## ユーザーストーリー

開発者として、CLIの全メッセージが英語で一貫したフォーマットで表示されてほしい。
なぜなら、グローバルなユーザーがエラーの原因と対処法をすぐに理解したいから。

## 詳細要件

### 共通エラーパターン

| エラー種別 | メッセージ例 | 終了コード |
|-----------|-------------|-----------|
| 未初期化 | `Error: .reqord/ directory not found. Run 'reqord init' first.` | 1 |
| ファイル読み込み | `Error: Failed to read req-000001.yaml: ENOENT` | 1 |
| バリデーション | `Error: Invalid value (see req-000010 for details)` | 1 |
| 成功 | （通常出力） | 0 |

### 実装方針

- 共通エラークラスまたはユーティリティ関数を作成
- `.reqord/` 未初期化チェックを全コマンドの共通前処理に
- `process.exit()` の呼び出しを一元管理
- エラー出力は stderr に統一

## 技術的制約

- 既存コマンドの動作を破壊しないこと
- エラーメッセージは英語で統一（グローバル展開対応）
- Node.js の exit code 規約に従う（0: 成功, 1: 一般エラー）

## エッジケース

- 権限エラー（ファイルの読み取り/書き込み不可）
- ディスク容量不足
- 不正なYAML形式のファイルが `.reqord/` に存在する場合
