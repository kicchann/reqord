# Web UIデザイン品質向上（ブランディング・レスポンシブ・モーション・個性化）

## 概要

現状のWeb UIはTailwindのデフォルトカラーやシステムフォントをそのまま使用しており、プロダクト固有のビジュアルアイデンティティがない。プロダクトカラーパレットの策定、Webフォント導入、StatusBadge等のカラー体系見直し、ナビゲーションバーのブランド表現が必要。

## ユーザーストーリー

Reqordユーザーとして、洗練されたブランディングとレスポンシブ対応のWeb UIを使いたい。
なぜなら、プロダクト固有のビジュアルアイデンティティがあることで、ツールへの信頼感と使いやすさが向上するから。

## 詳細要件

- プロダクトカラーパレットの策定とTailwind設定への反映
- Webフォントの導入（見出し・本文の使い分け）
- StatusBadge等のカラー体系見直し
- ナビゲーションバーのブランド表現
- レスポンシブ対応の改善
- モーション・トランジションの追加
