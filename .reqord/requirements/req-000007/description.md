# ローカルUI基本機能

## 概要

ローカルで動作するWebベースUIを提供し、要件の閲覧・編集・依存関係の可視化を行う。
**要件編集の主要手段**であり、スキーマバリデーション付きで安全にCRUD操作を行える。

## ユーザーストーリー

開発者として、ブラウザで要件を視覚的に管理したい。
なぜなら、要件の全体像と依存関係を直感的に把握でき、スキーマエラーなく安全に編集できるから。

## 画面構成

### 要件一覧画面

- テーブル形式（ID, Title, Status, Priority, Complexity）
- ステータス・優先度によるフィルタリング
- ソート機能（各カラム）
- 検索機能（タイトル、description内テキスト）

### 要件詳細画面

- JSONフィールドの構造化表示
- description.md のMarkdownレンダリング
- 成功基準のチェックリスト表示
- 依存関係の表示（blockedBy / blocks）

### 依存関係グラフ

- DAG（有向非巡回グラフ）として視覚化
- ノード: 要件（ステータスで色分け）
- エッジ: blockedBy/blocks 関係
- インタラクティブ（クリックで詳細表示）

### 編集機能（日常操作の主役）

- 要件の新規作成（フォーム形式、スキーマバリデーション付き）
- ステータス変更
- 優先度変更
- 成功基準の追加・編集・削除
- 依存関係の設定（ドラッグ&ドロップまたはセレクト）
- description.md の編集（react-markdownベースのプレビュー付きエディタ）
- 要件の削除（確認ダイアログ付き）
- すべての変更はスキーマバリデーション後にファイルシステムへ反映

## 技術スタック

- Next.js（App Router）
- @reqord/shared の型定義を使用
- ファイルシステムAPI経由でデータ読み書き
- react-markdown でMarkdownプレビュー・編集
- D3.js または React Flow で依存関係グラフ

## 技術的制約

- ローカルサーバーのみ（外部公開不要）
- ファイルシステム直接操作（DBなし）
- @reqord/shared パッケージの型安全性を維持
- レスポンシブ対応は最低限（デスクトップ優先）
